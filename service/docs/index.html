▶NotificationEndpointHTTP Endpoint/v1/context5 routes

Where the people a case or an approval is routed to are told. A route is a name (the "route to" of a monitor, or role:approver) and a web address that receives a JSON post, or a Slack incoming webhook. Setting one up sends records' existence, never their contents, to an outside address, so it needs the admin role and the address must be on the egress list.
